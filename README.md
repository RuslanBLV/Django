# Создание проекта "интернет-магазин"!

## Описание:

Создано приложение для продуктов, где хранится весь список продуктов их цена, фото, описание, дата 


## Использование:

Установите все зависимости которые хранятся в файле "requirements.txt"
Запустите сервер с помощью команды "python manage.py runserver" в консоли проекта, далее перейдите по ссылке.
Есть приложение "catalog" и "blog" 
В каталоге находится список всех продуктов которые опублокованы через admin, так же можно добавить или отредактировать какой то из продуктов
В блоге так же находится весь список созданных блогов которые опубликованы через admin, их можно отредактировать или добавить новые

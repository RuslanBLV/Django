# Создание проекта "интернет-магазин"

## Описание:

1. Создал новую директорию для проекта и настроил виртуальное окружение.
2. Инициализировал новый проект Django внутри этой директории.
3. Создал новое приложение под названием catalog в проекте.
4. Зарегистрировал приложение в настройках проекта.
5. Настроил маршрутизацию для нового приложения, добавив соответствующие URL-адреса.
6. Подготовил два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
7. Для стилизации страниц использовал Bootstrap.
8. Создал контроллер для отображения домашней страницы.
9. Создал контроллер для отображения страницы с контактной информацией.
10. Настроил маршрутизацию для этих контроллеров.
11. Реализовал форму обратной связи на странице контактов.
12. Настроил обработку данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.


## Использование:

Запустите сервер с помощью команды "python manage.py runserver" в консоли проекта, далее перейдите по ссылке.
